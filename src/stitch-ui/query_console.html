Can you show me a modern pattern for a robust database connection pool in Node.js?

KINETIC_AI

To establish a high-performance connection pool, you should leverage the Singleton pattern. This ensures that your application doesn't exhaust the database's available connections during peak traffic.

TypeScript
import { Pool } from 'pg';

// Initialize the Singleton instance
let poolInstance: Pool;

export const getPool = () => {
  if (!poolInstance) {
    poolInstance = new Pool({
      connectionString: process.env.DATABASE_URL,
      max: 20,
      idleTimeoutMillis: 30000,
      connectionTimeoutMillis: 2000,
    });
  }
  return poolInstance;
};

By defining a max limit and idleTimeout, you maintain a "Kinetic" state where connections are recycled efficiently without manual overhead.
